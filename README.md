# Zainab Malik — Portfolio (fixed profile photo)

This folder contains the portfolio website files. The profile image is included as `profile.jpg` and the HTML points to it using `./profile.jpg`.

## Files to upload together
- `index.html`
- `style.css`
- `script.js`
- `README.md`
- `profile.jpg`  ← important: this is the profile photo

## Update your existing GitHub Pages website
1. Download this ZIP and extract it on your computer (right-click → Extract All).
2. Open your GitHub repository: https://github.com/hafizazainab01/-portfolio
3. Click **Add file → Upload files**.
4. Open the extracted folder and select the five files listed above. Upload the files themselves, not the ZIP file and not the folder as a nested folder.
5. Make sure `index.html`, `style.css`, `script.js`, `README.md`, and `profile.jpg` appear together at the repository's top level (same screen, not inside another folder).
6. Scroll down. In the commit message box, type `Fix profile photo and portfolio files`.
7. Click **Commit changes**.
8. Wait a few minutes, then open https://hafizazainab01.github.io/-portfolio/ and refresh. If the old image is still cached, press **Ctrl + F5**.

If GitHub shows a conflict or asks to replace files, replace the existing website files with these corrected versions. Do not change your GitHub Pages settings.
